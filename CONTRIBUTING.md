# Contributing to Loom-ish

Thanks for helping improve Loom-ish.

## Before opening an issue

- Confirm the problem still occurs on the live site.
- Include your browser and operating system.
- Describe the recording settings you selected.
- Do not attach recordings containing private or sensitive information.

## Pull requests

Keep changes focused and preserve the project's core promises:

- Recording must remain local by default.
- No account should be required.
- The site must not silently upload or retain video.
- The recorder should remain usable on desktop Chrome and Edge.
- User-facing privacy and storage language must stay accurate.

Test recording, downloading, trimming, and responsive layout before submitting a pull request.
